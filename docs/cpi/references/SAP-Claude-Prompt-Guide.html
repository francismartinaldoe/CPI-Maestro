SAP Brand Claude Prompt Guide
May 2026

How to Use

1
Attach sap-brand.md In Claude, attach sap-brand.md from the SAP Brandspace SharePoint before pasting any prompt. This file links to all other brand references — Claude will retrieve specific files (charts, tables, shell, etc.) from it as needed.
2
Start with Prompt 1, then add components Prompt 1 creates the full page scaffold (shell bar, fonts, CSS variables, section cards). Use it first for any new file. Prompts 2–5 add components — paste them in follow-up messages to the same conversation.
3
Fill in the placeholders Replace all [BRACKETED] values with your actual data — titles, section descriptions, column definitions, numbers. Everything else in the prompts is a fixed specification and should not be changed.

Prompt 1 — Page Scaffold Always first

Foundation

Creates a complete, self-contained HTML page with shell bar, scroll-hide behavior, font loading, CSS variables, and empty section cards. Every SAP dashboard starts here.

Replace all [BRACKETED] values with your content 
Create a self-contained, single-file HTML dashboard page in the SAP Morning design system.

CONSTRAINTS
- No CSS frameworks (no Bootstrap, Tailwind, etc.)
- No external CSS files — all styles in one <style> block inside <head>
- Allowed external resources ONLY: '72' font (SAP CDN) and optionally Chart.js

FONT — load via @font-face (both weights required):
  font-family: '72'; font-weight: 400;
  src: url('https://sapui5.hana.ondemand.com/resources/sap/ui/core/themes/sap_horizon/fonts/72-Regular.woff2') format('woff2');

  font-family: '72'; font-weight: 700;
  src: url('https://sapui5.hana.ondemand.com/resources/sap/ui/core/themes/sap_horizon/fonts/72-Bold.woff2') format('woff2');

CSS VARIABLES (define in :root)
  --tx: #12171c;   /* primary text */
  --ts: #8ea4b8;   /* muted / secondary */
  --tm: #556475;   /* mid-tone */
  --br: #0070f2;   /* brand blue */

BODY
  font-family: '72', Arial, Helvetica, sans-serif;
  background: #fff; color: var(--tx); padding-top: 56px;

CONTENT WRAPPER (.lead)
  max-width: 1200px; margin: 0 auto; padding: 40px 40px 80px;
  display: flex; flex-direction: column; gap: 24px;

SHELL BAR (.top-bar)
  position: fixed; top: 0; left: 0; right: 0; z-index: 100;
  height: 56px; background: #f5f6f7; border-bottom: 1px solid #e8eaed;
  transition: transform 220ms ease-in-out;

  Inner (.top-bar__inner): max-width 1200px; margin 0 auto; padding 0 40px; display flex; align-items center;

  Slots (left → right):
  1. SAP logo SVG inline (height 32px — use standard SAP red/gold gradient logo)
  2. Divider: 1px wide × 22px tall; background #d5dadd; margin 0 16px; flex-shrink 0
  3. Product name: 17px, weight 700, color #12171c
  4. App name: 17px, weight 400, color #354a5f, margin-left 14px (baseline-aligned with product name)
  5. PI badge (optional): display inline-block; font-size 14px; font-weight 700; color #0040b0;
                          background #ebf8ff; border 1px solid #a6e0ff; border-radius 4px;
                          padding 1px 6px; margin-left 7px; vertical-align middle;
  6. Date: margin-left auto; font-size 12px; color #8ea4b8; white-space nowrap;

  Scroll-hide JS (add before </body>):
    let lastY = 0, upCount = 0;
    const bar = document.querySelector('.top-bar');
    window.addEventListener('scroll', () => {
      const y = window.scrollY;
      if (y < 10)         { bar.style.transform = ''; upCount = 0; }
      else if (y < lastY) { if (++upCount >= 2) bar.style.transform = ''; }
      else                 { bar.style.transform = 'translateY(-100%)'; upCount = 0; }
      lastY = y;
    }, { passive: true });

SECTION CARDS (.section-card)
  background: #fff; border: 1px solid #d9dde0; border-radius: 12px;
  padding: 32px 40px; box-shadow: 0 1px 4px rgba(0,50,165,.06);
  Use min-height: 180px for content cards; omit for chart sections.

  Header (.section-card__header): display flex; align-items center; gap 8px; margin-bottom 20px;
  Optional icon slot (.section-card__icon): width 32px; height 32px; display block;
  Label (.section-card__label):
    font-size: 14px; font-weight: 700; letter-spacing: 0.08em; text-transform: uppercase;
    color: #002a86;  ← ALWAYS Blue/10 #002a86, NEVER the brand blue #0070f2
    margin-bottom: 20px; (set to 0 when inside .section-card__header)

ACCENT BAR LABELS (.chip) — sub-section titles within cards

KPI Tiles

Adds a 4-tile summary grid inside an existing section card. Covers the simple, progress bar, two-number, and stacked bars tile variants.

TILE VARIANTS — choose per tile:

  SIMPLE: big number only + optional pill text.

  PROGRESS (e.g. "X of Y executed"):
    Fraction: big number + " / " + total (0.95rem, 700, #556475, baseline-aligned)

    Center divider: height 1.85rem; background rgba(0,0,0,.08); margin-bottom 0.35rem; align-self end;
    Each number: big value (.kpi-v) + small SVG priority icon (12×16px) + label (0.68rem, #556475)

  STACKED BARS (e.g. execution windows / sprint periods):
    Each sub-row: background rgba(0,112,242,.04); border 1px solid rgba(0,112,242,.13);

    Mini bar: height 4px; border-radius 2px; background rgba(0,112,242,.1);

Prompt 5 — Execution Status Donut Component

Inline SVG Donut

Adds an inline SVG donut chart (no Chart.js) showing test execution status breakdown. Uses semantic status colors (overrides blue-monochrome rule). Includes hover interaction and a color legend.

Attach sap-brand-charts.md for arc math reference 
Add an execution status donut chart as inline SVG. Do NOT use Chart.js for this.

SVG ELEMENT
  <svg viewBox="0 0 160 160" width="160" height="160" class="exec-donut">
  All circles: cx="80" cy="80" r="60" stroke-width="20" fill="none" stroke-linecap="butt"
  All segment circles: add transform="rotate(-90 80 80)" — starts arc at 12 o'clock

TRACK CIRCLE (render first, sits behind all segments)
  <circle cx="80" cy="80" r="60" fill="none" stroke="#eaecee" stroke-width="20"
          stroke-linecap="butt" class="exec-track"/>

ARC MATH (compute for each segment in order)
  Circumference C = 376.99  (= 2π × 60)
  Per segment:
    geometric_arc = C × (segment_count / total_count)
    visual_arc    = geometric_arc − 1.5              ← gap = 1.5 arc units
    offset        = −(sum of ALL prior geometric_arcs) − 0.75
  stroke-dasharray  = "{visual_arc} {C}"
  stroke-dashoffset = "{offset}"

STATUS COLORS — semantic override (permitted exception to blue-monochrome rule):
  Passed:      stroke="#256f3a"
  Failed:      stroke="#aa0808"
  Blocked:     stroke="#e76500"
  Aborted:     stroke="#475e75"
  Not Started: stroke="#eaecee"  ← same as track, visually blends in

RENDER ORDER (first = bottom layer): Not Started → Aborted → Blocked → Failed → Passed

CENTER OVERLAY
  Wrapper: position relative; width 160px; height 160px; flex-shrink 0;
  <div class="exec-donut-wrap"> containing the SVG + a center overlay:
  Overlay: position absolute; inset 0; display flex; flex-direction column;
           align-items center; justify-content center; pointer-events none;
  Big %:   font-size 1.9rem; font-weight 900; color #12171c; line-height 1;
           Value = Math.round(passed / total * 100) + '%'
  Label:   font-size 0.6rem; font-weight 600; color #8ea4b8;
           text-transform uppercase; letter-spacing 0.06em; margin-top 3px;
           Text: "EXECUTED"

HOVER BEHAVIOR
  CSS:
    .exec-donut.is-hovering circle:not(.exec-track) { opacity: .22; transition: opacity .15s; }
  JS per segment circle:
    mouseenter → add .is-hovering to <svg>, set this circle opacity to 1,
                 update center to show hovered count + status label (e.g. "142 Passed")
    mouseleave on <svg> → remove .is-hovering, restore center to total % + "EXECUTED"
  Mirror same hover on corresponding legend rows.

LEGEND (below or beside donut)
  Each row: flex; align-items center; gap 0.55rem;
  Color dot: 12×12px square, border-radius 3px (NOT a circle) — match segment stroke color
  Label text: 11px, color #556475
  Count: same size, color #12171c, font-weight 700

DEFINE
  Total TC count:      [TOTAL]
  Passed count:        [PASSED]
  Failed count:        [FAILED]
  Blocked count:       [BLOCKED]
  Aborted count:       [ABORTED]
  Not Started count:   [NOT_STARTED]
