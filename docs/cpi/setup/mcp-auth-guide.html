🔑 MCP Setup

SAP Jira MCP Authentication

Step-by-step guide to authenticate the SAP Jira MCP server in Claude Code. Required once per machine — credentials persist across sessions.

📡 What Is the SAP Jira MCP?

The SAP Jira MCP (Model Context Protocol) server connects Claude Code directly to your SAP Jira instance. Once authenticated, Claude can read and query Jira issues, capabilities, features, bugs, and test cases — without you copying data manually.

DetailValue
MCP Serversap-jira
Endpointhttps://mcp.jira./mcp
TypeHTTP (OAuth 2.0)
Auth MethodSAP SSO / Corporate credentials
Config location.claude/settings.json (pre-configured)
ℹ️ The MCP server is already configured in .claude/settings.json. You only need to authenticate — no manual configuration required.
✅ Prerequisites
1
Claude Code installed and running
Claude Code VSCode extension must be active. Verify by pressing Ctrl+Shift+P → "Claude Code: Open".
2
Claude repo opened in VSCode
Open the cloned ~/Claude folder in VSCode. Claude Code reads the MCP config from .claude/settings.json in the workspace root.
3
SAP corporate network / VPN active
You must be on the SAP corporate network or connected via VPN. The MCP endpoint https://mcp.jira. is internal-only.
🔐 Authentication — Step by Step
1
Open Claude Code in VSCode
Click the Claude Code icon in the sidebar, or press Ctrl+Shift+P → "Claude Code: Focus on Claude Code View".
2
Trigger MCP authentication
Type the following in the Claude Code chat and press Enter:
authenticate with SAP Jira
Alternatively, type /_tech-update — it will detect unauthenticated MCP and guide you through setup.
3
Claude triggers OAuth flow
Claude will call mcp__sap-jira__authenticate and return an authorization URL. It looks like:
https://mcp.jira./oauth/authorize?client_id=...&state=...&redirect_uri=http://localhost:PORT/callback
⚠️ The URL contains a one-time state parameter. Do not reload or share it.
4
Open the URL in your browser
Click or paste the authorization URL into your browser. Log in with your SAP corporate credentials (SSO).
5
Authorize the application
The browser will show a consent screen for the SAP Jira MCP. Click Authorize / Allow.
6
Copy the callback URL
After authorizing, the browser redirects to a localhost page that may fail to load. That is expected on remote/WSL setups.

Copy the full URL from the browser address bar. It looks like:
http://localhost:PORT/callback?code=AUTH_CODE&state=STATE_VALUE
7
Return the callback URL to Claude
Paste the full callback URL into Claude Code and say:
Here is the callback URL: http://localhost:PORT/callback?code=...&state=...
Claude will call mcp__sap-jira__complete_authentication with the callback URL to finish the OAuth flow.
8
Verify authentication
Claude will confirm: "SAP Jira MCP authenticated successfully."
Verify by running /-status — it should pull live data from Jira.
✓ Authentication complete. Claude can now read Jira issues, run JQL queries, and access program data directly.
🛠️ Troubleshooting
ProblemSolution
Authorization URL not generatedEnsure you are on SAP VPN / corporate network and the workspace contains .claude/settings.json. Run /_tech-update first.
Callback page shows error / doesn't loadExpected behaviour — copy the URL from address bar anyway; the code is embedded in the URL parameters.
Authentication expires / re-authentication neededRepeat from Step 2. SAP OAuth tokens expire; re-authenticate when Claude reports MCP connection errors.
MCP not listed in Claude CodeEnsure theClaude folder (not a subfolder) is open in VSCode. The .claude/ folder must be at workspace root.
VPN not connectedConnect to SAP VPN (GlobalProtect or equivalent). The mcp.jira. endpoint is not reachable from public internet.
🚀 What You Can Do After Authentication

Once authenticated, Claude can directly access your Jira data:

TaskHow
Check capability DoR/-capability-check SP-XXXX
Check feature DoR/-feature-check YOUR_JIRA_PROJECT-XXXX
Get bug counts for current sprint/-bug-query
Get program snapshot/-status
Query any Jira issueAsk Claude: "Show me YOUR_JIRA_PROJECT-1234"
Run custom JQLAsk Claude: "Run this JQL: project = YOUR_JIRA_PROJECT AND ..."
ℹ️ Credentials are stored securely by Claude Code. You do not need to re-authenticate each session, but tokens may expire after extended inactivity or token rotation.
